# strutils

A tiny collection of string helper functions, used as a first-PR practice repo.

## Functions

- `is_palindrome(s)` — checks if a string reads the same forwards and backwards
- `reverse_words(s)` — reverses the order of words in a string
- `title_case(s)` — capitalizes the first letter of each word

## Running tests

```bash
python3 -m unittest
```
